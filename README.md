## ✨ Features

- 💰 Track Money In
- 💸 Track Money Out
- 📊 Weekly budgets
- 🏷️ Custom categories
- ✅ Weekly checklist
- 📅 Previous week history
- 📈 Spending overview
- 💾 Local data storage
- 📤 Import/export backups
- 📱 Mobile & desktop friendly

## 🔒 Privacy

- 100% local-first
- No bank connections
- No cloud database
- No tracking or ads
- Financial data stays on your device

- JavaScript
- Local storage / IndexedDB
